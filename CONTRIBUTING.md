# Contributing

Issues and proposals are welcome once this repository is published.

**Before submitting code:** contributor terms need to be finalized so ownership, attribution, noncommercial distribution, and potential separate commercial relicensing rights are unambiguous. Until those terms exist, do not submit unsolicited third-party code or assets.

Do not remove or replace the historical QB64 originals. Place ports in their respective platform directory, accompany changes with repeatable tests, update relevant specifications, and use descriptive commit messages.
